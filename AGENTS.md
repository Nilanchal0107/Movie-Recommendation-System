# Project Instructions & Behavioral Rules

Refer to [rules.md](./rules.md) for full project rules.

## Git Operations Rule (Strict)
- Antigravity is strictly restricted from running any write/mutation Git commands (`git add`, `git commit`, `git push`, `git reset`, `git checkout`, `git stash`, etc.).
- Only read-only `git status` and `git log` commands are allowed.
- At the end of each completed phase or milestone, provide the suggested `git add` and `git commit` commands for the USER to execute manually.
